# np355v4c-fanctl

Минимальная Linux-утилита для управления вентилятором на **Samsung NP355V4C-S01RU**.

Поддерживаются только два проверенных режима:

```bash
sudo ./np355v4c-fanctl full-on
sudo ./np355v4c-fanctl normal
```

| Режим | Действие |
|---|---|
| `full-on` | Принудительно включает максимальные обороты вентилятора. |
| `normal` | Возвращает штатное автоматическое управление EC. |

> **Предупреждение:** программа обращается напрямую к Embedded Controller (EC) через I/O-порты. Она проверена на одном конкретном Samsung NP355V4C-S01RU с BIOS P02AAN и EC ENE KB9012. Не запускайте её на другом ноутбуке или похожей модели без отдельной проверки.

## Сборка

Нужны Linux, компилятор C и заголовок `sys/io.h`:

```bash
cc -O2 -Wall -Wextra -Werror -o np355v4c-fanctl np355v4c-fanctl.c
```

Для доступа к портам программа использует `ioperm()`, поэтому запускать её нужно от root:

```bash
sudo ./np355v4c-fanctl full-on
sudo ./np355v4c-fanctl normal
```

## Принцип работы

На этой модели команда управления вентилятором передаётся не через обычную ACPI EC-пару `0x62/0x66`, а через отдельный EC-совместимый интерфейс:

```text
0x68  — data port
0x6C  — command/status port
```

Перед каждой записью программа ожидает, пока EC освободит входной буфер:

```text
(inb(0x6C) & 0x02) == 0
```

После этого она передаёт двухбайтную команду:

```text
Full On:
  outb(0x59, 0x6C)  # команда EC
  outb(0x77, 0x68)  # режим максимальных оборотов

Normal:
  outb(0x59, 0x6C)  # команда EC
  outb(0x76, 0x68)  # штатное автоматическое управление
```

До основной команды библиотека-оригинал также однократно читает `0x68`; утилита сохраняет этот шаг для соответствия проверенной последовательности.

Программа делает максимум `0x2710` проверок готовности EC. Если готовность не наступает, она завершается с ошибкой и не выполняет соответствующую следующую запись.

## Почему нет чтения ответа EC

Оригинальная Windows-утилита использует дополнительную ответную часть протокола. Однако для двух известных команд семантика её параметра ответа не была полностью восстановлена. Практический тест показал, что сами status-gated записи работают: вентилятор физически достиг максимальных оборотов после `0x59, 0x77`, а затем успешно вернулся в `normal` через `0x59, 0x76`.

Поэтому эта утилита сознательно подтверждает только то, что может доказать: готовность EC к записи и успешное выполнение проверенной последовательности портовых записей. Она не выдаёт неподтверждённое утверждение о содержимом ответа EC.

## Ограничения и безопасность

- Это **не** стандартный `hwmon`/PWM-интерфейс Linux.
- В программе нет произвольного режима, порта, команды или payload: только `full-on` и `normal`.
- `full-on` остаётся активным, пока не будет вызван `normal` либо EC не изменит состояние из-за другого события.
- Не оставляйте ноутбук без присмотра в режиме `full-on`.
- Перед экспериментами держите готовой команду возврата:

  ```bash
  sudo ./np355v4c-fanctl normal
  ```

## Проверенная конфигурация

| Параметр | Значение |
|---|---|
| Ноутбук | Samsung NP355V4C-S01RU |
| BIOS | P02AAN |
| Платформа | AMD A10-4600M / AMD FCH |
| EC | ENE KB9012 |
| Результат | `full-on` физически раскручивает вентилятор до максимума; `normal` возвращает штатный режим. |
